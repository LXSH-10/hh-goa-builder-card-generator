# Project notes

- This is a Next.js 16 App Router project using TypeScript and Tailwind CSS v4.
- The main UI is rendered by `components/unified-id-generator.tsx` from `app/page.tsx`.
- Package management uses pnpm 10.4.1.
- Keep user-visible behavior accessible, responsive, and compatible with the existing HH Goa visual system.
- Run `pnpm build` after source or dependency changes.
