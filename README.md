# hh-goa-builder-card-generator
A web tool where someone uploads a photo and instantly gets back a branded HH Goa 2026  graphic, ready to download and share on X.  Format : Builder ID Card   A card with the uploaded photo + name + a couple of fun fields (your stack/role, a generated  'builder title') laid out like an event badge, designed to be posted as an image, not printed.
